# 08. Прошивка

## Что прошиваем
`dist/lcpi-joy.img` — узел джойстиков.

## USB Maskrom
1. Драйвер Rockchip:
   `C:\Users\yoy70\DriverAssitant_v5.12\DriverAssitant_v5.12\DriverInstall.exe`.
2. Зажать **BOOT** при подключении USB; `upgrade_tool ld` →
   `Maskrom`, `VID_2207/PID_110C`.
3. Прошить:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File `
  .\scripts\flash_usb.ps1 -Image .\dist\lcpi-joy.img -Force
```
или SocToolKit → `RV1106` → `Firmware` → `Upgrade`.

## microSD
```powershell
.\scripts\flash_sd.ps1 -Image .\dist\lcpi-joy.img -DiskNumber <N> -Verify
```

## После прошивки
- UART 115200: Linux, разделы NAND.
- `ping 192.168.127.251`, SSH `root`/`luckfox`.
- 4 пульта → `/dev/input/by-path`, `/api/v1/slots`, НСУ
  `/api/v1/joysticks` → `remote-pi4joy-1..4`.
- Проверить назначения: слот 3 → C-003, слот 4 → C-004.
- Питание: powered hub, 5 В ≥4.75 В под нагрузкой.

## Восстановление
- Не грузится: снова Maskrom + `upgrade_tool uf`.
- Сбой NAND: полный образ перезаписывает разделы.
- Сбой SD: перезаписать карту, NAND не трогается.
