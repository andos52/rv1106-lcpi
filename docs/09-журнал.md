# 09. Журнал

## 2026-11-20 — USB-топология и слоты
- После подключения через новый хаб путь стал `0:1.7`; старый
  `slots.json` держал все 4 слота за `0:1.1..4`, поэтому pi4joy
  `online:0`, НСУ не видел пульт.
- Исправлено: менеджер слотов освобождает слот offline-устройства;
  `slots.default.json` пустой; env перезаписан без BOM.
- Итог: `0:1.7 → слот 1`, НСУ видит `remote-pi4joy-1`; образ `da4d0cf0…6ee3`.

## 2026-11-15 — узел джойстиков
- Плата LCPI-RV1106 V1.4 (RV1106G2, 128 МБ, SPI NAND 256 МБ) определена,
  Maskrom/прошивка/UART/SSH/Ethernet проверены.
- Собран образ `lcpi_joy`: DWC3 host, USB HID/evdev, eudev, CMA 32M.
- Проверены 4 TX12, слоты 1–4, `remote-pi4joy-1..4`, назначения бортам.
- Исправлено перемешивание слотов: старые sticky `remote-3→4`,
  `remote-4→3` заменены на `remote-1..4 → 1..4`.
- Исправлен idle-трафик pi4joy: 50 Гц → keepalive 5 Гц при неизменном
  состоянии; измерено ~36.5 → ~12.8 КБ/с (джиттер TX12).
- Для джиттера добавлено квантование ключа 5 мкс; точные значения в кадре
  не меняются. Образ: `4f20e2dd…578b0b8`.
- Левая колонка телеметрии зафиксирована по ID: 1…4 сверху вниз.
- Минимальный образ: убраны лишние сервисы, слоты запечены.
- API-контракт зафиксирован в `03-api-contract.md`.
