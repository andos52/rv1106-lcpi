# 06. Архитектура радио-тракта masha

## 1. Схема
```
[MIPI CSI SC3336]
      │ rkisp / V4L2
      ▼
[RV1106G2] ── MPP VENC (H.265) ──► vcpd
      │                              │ ULAMA VIDEO (radiod IPC)
      │                              ▼
      │                        radiod (TDMA, ULAMA L1/L2/L3)
      │                              │ pcap injection
      │                              ▼
      │                     mon0 / AR9271 (ch6, 2437 МГц)
      │                              │ 802.11
      │                              ▼
      │                     radiod на НСУ ─► ulama-gw ─► cascade-core ─► UI
      └── UVCP READY/STOP/PING ◄── radiod/ulama-gw ◄── cascade-core
```

Видео — только от борта к НСУ. Обратного видео нет; вниз идут ULAMA
CTRL/телеметрия и UVCP.

## 2. Состав образа
- U-Boot + loader (SPI NAND 256 МБ).
- Kernel RV1106: rkisp/MPP, SPI NAND, Ethernet, USB.
- Buildroot rootfs (`luckfox_pico_defconfig` v1.8.0).
- `/oem/usr/bin`: `radiod`, `ctrld`, `vcpd`, `ushd`, `log-persist.sh`.
- `/oem/usr/ko`: `ath9k_htc`/`ath9ku`, `mac80211`, `cfg80211`, `libarc4`.
- `/lib/firmware/ath9k_htc/htc_9271.fw`.
- Init: `S39wifi` (mon0), `S96radiod` (radiod→ctrld→vcpd→ushd).
- Конфиги: `/etc/vcpd.conf`, `/etc/radiod.conf`, `/etc/ctrld.conf`.

## 3. Видеотракт
1. Камера отдаёт кадры через rkisp; `vcpd` читает Annex-B access unit.
2. MPP кодирует H.265 (по умолчанию 320×240@30, 128 кбит/с, GOP 6).
3. `vcpd` режет кадр на фрагменты `frag_mtu=1440` и отправляет через
   `transport=radiod` (ULAMA IPC → radiod).
4. `radiod` пакетирует ULAMA в 802.11 (pcap injection) и шлёт в эфир;
   ACK/повторы и TDMA — на его стороне.
5. `ulama-gw` на НСУ собирает кадр, оборачивает в `cascade-frame` VIDEO и
   отдаёт `cascade-core`.

Дополнительно: XOR-FEC для ключевых кадров, повторные копии
(`kf_extra_copies`), `tx_pacing_us`, `smartp`/virtual-IDR.

## 4. ULAMA-кадр
Источник истины: `media/ulama/include/ulama/ulama_frame.h`,
`media/ulama/src/core/ulama_frame.c` (v1.8.0).

| Смещение | Размер | Поле | Значение |
|---|---|---|---|
| 0 | 1 | magic | `0xA5` |
| 1 | 1 | version | `0x02` |
| 2 | 1 | src_node | ID борта |
| 3 | 1 | dst_node | `254` (НСУ) |
| 4 | 1 | flags | ACK/FRAG/VIDEO_KEYFRAME и др. |
| 5 | 1 | traffic_class | VIDEO/CTRL/… |
| 6 | 2 | seq | little-endian |
| 8 | 1 | frag_idx | индекс |
| 9 | 1 | frag_total | всего фрагментов |
| 10 | 1 | ttl | 8 |
| 11 | 1 | reserved | 0 |
| 12 | 2 | crc16 | CRC16-CCITT над 0..11, LE |
| 14 | N | payload | ≤ 2285, в vcpd 1440 |

Флаги: `ACK_REQ=0x01`, `IS_ACK=0x02`, `FRAGMENT=0x04`,
`LAST_FRAGMENT=0x08`, `MESH_RELAY=0x10`, `ROUTE_DISC=0x20`,
`DEGRADED=0x40`, `DUP_ALLOWED=0x80`; для VIDEO бит `0x40` —
`VIDEO_KEYFRAME`.

## 5. UVCP
Текстовые сообщения `UVCP/1 …` внутри ULAMA:
- НСУ → борт: `READY`, `STOP`, `PING`;
- борт → НСУ: `PONG`.
`READY` продлевает lease и запускает/продолжает поток; `always_on=true`
держит камеру и энкодер тёплыми, меняя только частоту кадров.

## 6. Контракт с НСУ
- НСУ: AR9271 + `radiod` (monitor ch6) + `ulama-gw` + `cascade-core`.
- Номер борта (`node.id`) должен совпадать с настройками НСУ.
- Канал и TX-параметры radiod одинаковы на обоих концах (ch6/2437).
- Wi-Fi AP, IP-адреса и WireGuard **не используются**.
- Проверка: `iw dev mon0 info`, логи radiod/vcpd, видео в UI.

## 7. Надёжность и ресурсы
- `S39wifi` повторяет bind AR9271, не делает rmmod при здоровом `mon0`.
- USB watchdog переинициализирует стек при пропадании стика.
- `log-persist.sh` копирует логи в `/userdata/log`.
- 128 МБ RAM: CMA 32 МБ, без лишних сервисов; следить за RSS.
- Type-C один: стик питается через powered hub/OTG.
