# 17. Джойстики: надёжность, две унаследованные проблемы

Радио/камера заморожены. Цель этого этапа — минимальный, предсказуемый
образ `lcpi_joy`: только USB-HID, udev, сеть и pi4joy. Главное — чтобы
пульт появлялся быстро и привязка к борту не «уезжала».

## 1. Две проблемы из `masha-gcs`

Файл-источник: `masha-gcs/docs/2026-11-14-masha-gcs-control-problems-analysis.md`
(Проблема 1 и Проблема 2).

### 1.1. Проблема 1 — «долгое появление на НСУ»
**Что видит оператор:** при переподключении (реплаг) пульта карточка слота
на НСУ остаётся offline 17–25 секунд; первое подключение после включения —
быстрое.

**Причина (подтверждена):**
- задержка целиком в USB-энумерации: TX12 при `USB Mode = Ask` поднимает
  USB-стек с задержкой; Linux получает `device descriptor read/64,
  error -32`, затем `-110` и повторяет порт;
- усугубляют: спящий USB-порт/хаб, плохое питание, длинный/дешёвый кабель;
- станционная часть добавляла ещё до ~5 с из-за UI-watchdog: сокет
  закрывался через 4 с тишины, а snapshot не пересылался (живые оси
  выключены). Это уже исправлено heartbeat'ом/таймаутом, но проверить
  надо.

**Как увидеть и измерить:**
1. На плате, в отдельной консоли:
   ```sh
   dmesg -w -T | grep -iE 'usb|hid|input|1209|descriptor'
   ```
2. В другой консоли — скрипт замера появления:
   ```sh
   /opt/pi4joy/joy_replug_test.sh 120
   # или из проекта: scripts/joy_replug_test.sh (запускать на плате)
   ```
3. Выдернуть и вставить кабель пульта, засечь:
   - `USB disconnect` → `New USB device found`/`input: OpenTX`;
   - появление `*-event-joystick` в скрипте;
   - `pi4joy /healthz` → `online:1`;
   - карточка в UI.
4. Повторить 10 раз на каждом порту/пульте.

**Критерий «исправлено»:**
- USB-событие → `New USB device found` ≤ **1.5 с**;
- нет `descriptor ... error -32/-110` (или единичные, без 15-секундных
  повторов);
- pi4joy online ≤ **1.5 с**, UI ≤ **3 с**;
- 10/10 реплагов без зависаний.

**Что делать, если не так:**
- на пульте: `SYS → Radio Setup → USB Mode = Joystick` (не `Ask`);
- сначала включить пульт, дождаться главного экрана, потом вставлять USB;
- powered USB hub, короткий качественный кабель, измерить 5 В под
  нагрузкой;
- запасной вариант на станции/плате: `usbcore.old_scheme_first=1`,
  `usbcore.initial_descriptor_timeout=1000` (откат: `0`/`5000`);
- udev-правило `power/control=on` для `1209`, `0483`, хабов.

### 1.2. Проблема 2 — «неправильное назначение»
**Что видит оператор:** назначает 4-й пульт на борт 1; первый пульт
(был на борту 1) теряет и активную, и сохранённую привязку, автоназначение
уводит его на другой борт; после перезагрузки он не возвращается на 1.
В карточке видно только «pi4joy #N», без имени и USB-порта — перестановка
пультов по портам меняет слоты незаметно.

**Причина:** в `registry.go` при ручном назначении на занятый борт
вытесненный пульт удаляется вместе с `sticky`, затем `autoAssignLocked()`
ставит его на первый свободный борт. Плюс ingest от pi4joy не передаёт
`name/path`, поэтому оператор не видит, какой физический пульт где.

**Как воспроизвести (3–4 пульта, 4 борта):**
1. Подключить A, B, C → автоназначение `A→1, B→2, C→3`.
2. Подключить D (не назначен), в UI назначить **D → борт 1**.
3. Ожидаемое правильное поведение: `A` показывает «НЕТ», но сохраняет
   намерение вернуться на 1; автоназначение **не** уводит A на 3/4.
4. Зафиксировать:
   ```sh
   curl -s http://192.168.127.250/api/v1/joysticks
   sudo -n cat /var/lib/cascade/joystick-assignments.json
   ```
5. Перезагрузить/переподключить A: при свободном борте 1 он должен
   вернуться на 1.
6. Переставить пульты по USB-портам и проверить, что в карточке видно
   имя/порт и слоты не «меняются местами» незаметно.

**Критерий «исправлено»:**
- вытесненный A: `assigned=-1`, но `sticky/saved=1` сохранён;
- A не получает другой борт как побочный эффект;
- после реконнекта/reboot A возвращается на 1, если борт свободен;
- назначение на несуществующий борт отклоняется (400);
- в карточке есть имя пульта и USB-путь.

**Где исправлять:** это NSU (`masha-gcs`), не прошивка платы.
Плата со своей стороны даёт стабильные слоты и `name/path`.

## 2. Минимальный образ (оптимизация)
Оставить только необходимое:
- **оставить:** `S10udev`, `S20linkmount`, `S40network`, `S41eth0-static`
  (или DHCP), `S50sshd`, `S95pi4joy`, `/opt/pi4joy`, `/userdata/pi4joy`;
- **убрать:** radio/camera/media (`S39wifi`, `S96radiod`, `S21appinit`,
  `S60micinit`, `S50usbdevice`, `S90usb-watchdog`, `S99usb0config`,
  `S99hciinit`), `S99python`, `S99buildspot-ssh`, telnet;
- не запускать второй экземпляр pi4joy; watchdog/перезапуск — один;
- логи в tmpfs, без записи в NAND; userdata только для `slots.json`;
- статический `.251`; NSU подключается по WS;
- eudev нужен для `/dev/input/by-path`, не убирать.

### Надёжность
- **Сделано:** дефолтный `slots.json` запечён в
  `/opt/pi4joy/slots.default.json` и копируется в `/userdata/pi4joy/`
  при первом старте (порты `.3→1, .4→2, .1→3, .2→4`), поэтому перепрошивка
  userdata больше не меняет слоты.
- **Сделано:** из образа убраны radio/gadget/camera-сервисы, `S99python`,
  `S99buildspot-ssh`, `S50telnet`; `S50usbdevice`, `S60micinit`,
  `S99usb0config`, `S99hciinit` переведены в `.disabled`. RkLunch на
  текущем образе отсутствует, `S21appinit` — no-op.
- Watchdog pi4joy: перезапуск при падении, но без «двойников» — следующий
  шаг (сейчас сервис запускается один раз).
- Проверка: 4 пульта, 30–60 минут, 20 hot-plug, 10 power-cycle, reboot.
- USB: powered hub 5 В ≥2.5 А; мерить под нагрузкой.
- NSU: snapshot heartbeat 1 Гц, socket timeout 6 с, sticky сохраняется,
  `manualUnassigned`, валидация `drone_id`, имя/порт в карточке.

## 3. Матрица проверок
| # | Проверка | Проход |
|---|---|---|
| 1 | Реплаг ×10 на порт | ≤1.5 с, без `-32/-110` |
| 2 | Онлайн в UI после реплага | ≤3 с |
| 3 | 4 пульта одновременно | 4 слота online, каналы идут |
| 4 | Вытеснение A при D→1 | A «НЕТ», sticky=1 |
| 5 | Реконнект/reboot A | A снова на 1 |
| 6 | Перестановка портов | имя/порт видны, слот не «уезжает» |
| 7 | 20 hot-plug | без зависаний/дублей |
| 8 | 10 power-cycle | `.251`, слоты, NSU WS восстанавливаются |
| 9 | 30–60 мин | RAM/CPU/температура в норме |
| 10 | Питание | 5 В не ниже 4.75 под нагрузкой |

## 4. Артефакты для разбора
При сбоях собрать:
```sh
dmesg -T | tail -200
journalctl -u pi4joy -S -10m --no-pager
cat /dev/input/by-path/*-event-joystick 2>/dev/null   # имена
wget -qO- http://127.0.0.1:8090/healthz
wget -qO- http://127.0.0.1:8090/api/v1/slots
```
На НСУ: `journalctl -u cascade-core -S -10m`, `joystick-assignments.json`,
`/api/v1/joysticks`, состояние WS в DevTools.

4. Прогнать матрицу; сравнить с этим файлом; только потом менять ещё.
