## 2. USB Maskrom (основной путь)
1. Драйвер Rockchip:
   `C:\Users\yoy70\DriverAssitant_v5.12\DriverAssitant_v5.12\DriverInstall.exe`.
2. **BOOT** удерживать при подключении USB (проверено) либо
   `reboot loader` из Linux.
3. `upgrade_tool ld` → `Maskrom`, `VID_2207/PID_110C`.
4. Прошить:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File `
     .\scripts\flash_usb.ps1 -Image <update.img> -Force
   ```
   (обычный запуск `.ps1` может блокироваться ExecutionPolicy)
   или `upgrade_tool uf <update.img>`, или SocToolKit → `RV1106` →
   `Firmware` → `Upgrade`.
5. Перезагрузить, снять BOOT, проверить UART.

## 3. microSD
```powershell
Get-Disk | Format-Table Number,FriendlyName,BusType,Size
.\scripts\flash_sd.ps1 -Image <img> -DiskNumber <N> -Verify
```
Скрипт требует `ERASE <N>`, переводит диск offline, пишет и сверяет SHA256.
Если плата грузится с NAND, а не SD — изменить порядок загрузки/стереть NAND.

## 4. Проверка bring-up образа
- Ethernet в роутер с DHCP, найти IP (lease/`arp -a`), затем:
  ```sh
  ssh root@<ip>        # пароль luckfox
  uname -a; free -h; cat /proc/mtd; df -h
  ls -l /dev/video*; dmesg | grep -i sc3336
  lsusb
  ```
- Wi-Fi в bring-up образе не поднимется: нет `wpa_supplicant`.
- vcpd в bring-up — заглушка ULAMA/UDP, не радио.

## 5. Проверка радио-образа
UART (скорость уточнить: 115200/1500000), затем:
```sh
/etc/init.d/S39wifi status
iw dev mon0 info
lsmod | grep -E 'ath9k|mac80211|cfg80211'
/etc/init.d/S96radiod status
cat /var/log/vcpd/vcpd.log
```
Ожидается: `mon0` monitor ch6, radiod/ctrld/vcpd запущены, на НСУ идёт видео.
Если камеры нет — проверить `source=` в `/etc/vcpd.conf` и `/dev/video*`.

## 6. Восстановление
- Не грузится: снова Maskrom + `upgrade_tool uf`.
- Сбой NAND: полный образ перезаписывает разделы; при необходимости erase.
- Сбой SD: перезаписать карту, NAND не трогается.
- Нет UART: проверить питание 5 В/2 А, кабель, драйвер, скорость.

## 7. Замечания
- Питание при прошивке стабильное; USB не отключать.
- Сохранять `update.img` и SHA256 в `dist/`.
- Для радио нужен AR9271 и питание USB-стика (powered hub/OTG).
