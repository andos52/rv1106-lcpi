# Плата LCPI-RV1106 V1.4 (LC Technology)

## Идентификация
| Признак | Значение |
|---|---|
| SoC | Rockchip **RV1106G2**, маркировка `HBBMAG94Y`, `2519` (партия/дата: 2025 г., 19-я неделя) |
| Шелкография | `LCPI-RV1106_V1.4`, `303RV1106G2`, `www.lctech.cc` |
| Производитель | Shenzhen LC Technology (chinalctech.com / lctech-inc.com) |
| Board ID | `303RV1106G2` |
| Версия | V1.4 |

**Это не Luckfox.** У Luckfox другие платы (Pico / Pro / Max / Ultra) и своя
маркировка. Готовые образы и DTS Luckfox напрямую не подходят; SDK Luckfox
используется только как база для собственной сборки под LCPI (другой DTS,
флеш-чип и периферия).

## Характеристики
| Параметр | Значение |
|---|---|
| CPU | Cortex-A7 @ 1.2 ГГц + RISC-V (Syntacore SCR1) |
| NPU | 0.5 TOPS INT8 |
| VPU | H.264/H.265 энкодер (до level 5.0) |
| RAM | **128 МиБ DDR**, интегрирована в корпус RV1106G2 |
| Постоянная память | **256 МиБ SPI NAND**, Winbond `W25N02KVZEIR` (2 Гбит) |
| Слот карты | microSD / TF, до 128 ГБ |
| Ethernet | 1 × 100 Мбит |
| USB | Type-C (питание 5 В / 2 А) |
| Отладка | UART 3.3 В TTL на 40-pin GPIO |
| Прочее | 40-pin GPIO, MIPI CSI, RTC с батарейкой, SPI/I2C/UART |

## Данные производителя (фото и инструкция LC Tech)
- Кнопки **BOOT** и **RESET**; для прошивки BOOT удерживается при подаче питания.
- **Type-C**: питание + порт прошивки (device). Отдельного USB-A хоста нет.
- **UART**: отдельные пины, подключение через USB-TTL 3.3 В.
- **Камера**: разъём под **SC3336 3MP** (Camera A).
- **Ethernet**: HanRun HR911105A, 100 Мбит.
- microSD, SPI NAND 256 МБ, LED-индикатор, разъём BAT (RTC).
- Габариты 30 × 68.5 мм, 26 г.
- Штатный образ LC Tech (по скриншоту инструкции): hostname `luckfox pico`,
  логин `root` / пароль `luckfox`, `eth0` по DHCP, `usb0` RNDIS —
  то есть плата собрана на Luckfox/Rockchip SDK.
- Прошивка по инструкции LC: SocToolKit → чип `RV1106`, BOOT при
  подключении USB, `Search Path` → образ → `Download`.

Важно: на фото продукта встречается RV1106**G3**, но на нашей плате
маркировка **RV1106G2** (128 МБ), ревизия `LCPI-RV1106_V1.4`,
board ID `303RV1106G2`.

## GPIO-заголовок 2×20
- На плате **40 отверстий в два ряда** вдоль края (2×20), без подписей;
  в комплекте идут две планки 1×20 для пайки.
- Это **не Raspberry Pi** и не совпадает с Luckfox: готовой официальной
  pinout для LCPI-RV1106 V1.4 в открытом доступе нет.
- Не подключать периферию по распиновке Luckfox/Pi без проверки.
- Для проекта заголовок почти не нужен: камера — FPC-разъём, Wi-Fi — USB,
  а из GPIO нужны только **UART TX/RX/GND** для консоли.
- Как найти UART без схемы:
  1. GND — прозвонить с экраном USB-C/монтажным отверстием.
  2. 3.3 В/5 В — измерить вольтметром, но не подключать VCC адаптера.
  3. TX — при загрузке на пине будет быстрый лог; слушать USB-TTL RX
     на 115200 и 1500000.
  4. RX — после найденного TX подать сигнал через резистор 1 кОм.

### Подключение USB-TTL (3.3 В)
| USB-TTL | Плата | Примечание |
|---|---|---|
| GND | GND (прозвонить) | общий провод обязателен |
| RX | UART TX (кандидат) | только слушать, безопасно |
| TX | UART RX (через 1 кОм) | подключать после находки TX |
| VCC/5V | **не подключать** | плата питается от Type-C |

Параметры: 8N1, **115200** (подтверждено на этой плате), альтернативно
1500000. Если адаптер 5 В — поставить делитель/level shifter на линии TX
адаптера; VCC не соединять. Тестировать по одному пину: подключить GND +
RX, включить плату, искать в логе `U-Boot`/`Starting kernel`; затем искать RX.
Фактически проверено: UART работает на 115200, логин `root`/`luckfox`.

- Точная схема/пиноут — только у LC Tech (запросить у продавца
  «原理图/引脚定义» для LCPI-RV1106 V1.4).

## Что это значит для памяти
- **128 МБ DDR** — ОЗУ: при выключении теряется, ОС там не хранится.
- **256 МБ SPI NAND** — постоянная память: сюда штатно шьётся система
  (`update.img`), загрузчик читает её при старте.
- **microSD** — альтернативный носитель для загрузки/экспериментов.

Итого: система живёт в SPI NAND (256 МБ) или на microSD; RAM только для работы.
