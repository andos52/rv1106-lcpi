# Документация проекта RV1106

Актуальная цель — полевой узел masha на LCPI-RV1106 V1.4:
USB **AR9271** + `ath9k_htc`/`ath9ku` + `radiod`/ULAMA + `vcpd
--transport radiod`. LTE/WireGuard-вариант `bort4g` HEAD не используется.

## Индекс
- `01-плата.md` — идентификация, характеристики, память
- `02-прошивка.md` — источники образа и способы прошивки
- `03-чеклист.md` — bring-up и радио-проверки
- `04-существующие-инструменты.md` — SDK, worktree, инструменты
- `05-требования.md` — требования радио-режима
- `06-архитектура.md` — радио-тракт, ULAMA/UVCP, контракт с НСУ
- `07-сборка.md` — сборка masha v1.8.0 под LCPI
- `08-прошивка.md` — USB Maskrom, microSD, восстановление
- `09-план.md` — этапы, решения, риски
- `10-журнал.md` — хронология (исторические записи сохранены)
- `11-анализ-masha.md` — разбор masha/bort4g, почему выбран радио-режим
- `12-pi4joy.md` — вторая прошивка: замена Pi4Joy (приоритет)
- `13-измерения.md` — UART, RAM/CMA, NAND, USB, Ethernet, камера
- `14-сеть-адреса.md` — IP НСУ/Pi4Joy/бортов и сервисов
- `15-радио.md` — радио-прошивка дрона: сборка, проверки, риски
- `16-сравнение-luckfox.md` — LCPI-RV1106 vs Luckfox Pico Ultra

## Текущее состояние
- Прошит bring-up образ (luxfox), проверен по UART: Linux, root/luckfox,
  NAND OK. SSH по Ethernet не проверен.
- Ограничения bring-up: RAM 54 МБ (CMA 66M), USB-хост не поднят,
  `/dev/video*` нет.
- Радио-сборка v1.8.0: Buildroot source восстановлен, `allsave` идёт.
- Камера, `mon0`, `radiod` и видео на НСУ ещё не проверены.
