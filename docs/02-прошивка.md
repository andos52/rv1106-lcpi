# Варианты и источники прошивки

## 1. Образ должен быть под LCPI-RV1106 V1.4
Нужен образ для RV1106**G2** (128 МБ RAM), SPI NAND `W25N02KV` (256 МБ),
Ethernet и MIPI CSI SC3336 этой платы.

- Готовые образы Luckfox Pico (Pro/Max/Ultra) **не подходят**: другой DTS,
  флеш и периферия.
- SDK Luckfox/masha используется только как **база для своей сборки**.
- Штатный образ LC Tech в открытом доступе не найден.

## 2. Какие образы есть в проекте
| Образ | База | Назначение | Статус |
|---|---|---|---|
| Bring-up | `usalko/luxfox` + LCPI DTS | проверить загрузку, NAND, Ethernet, SSH | **прошит** |
| Радио | masha `v1.8.0` (`5e7ad171c3`) + LCPI DTS | целевой: AR9271 + `radiod`/ULAMA | сборка не завершена |

Bring-up образ содержит заглушку видео (ULAMA/UDP на `10.0.0.254`),
Wi-Fi STA-скрипт без `wpa_supplicant` и **не является** целевой прошивкой.

## 3. Прошивка через USB Maskrom (основной путь)
1. Драйвер Rockchip:
   `C:\Users\yoy70\DriverAssitant_v5.12\DriverAssitant_v5.12\DriverInstall.exe`.
2. Ввести плату в **Maskrom/Loader**: удерживать **BOOT** при подключении
   USB (проверено), либо `reboot loader` из работающей системы.
3. Проверить: `upgrade_tool ld` → `Maskrom`, `VID_2207/PID_110C`.
4. Прошить `update.img`:
   - GUI: `C:\Users\yoy70\SocToolKit\SocToolKit.exe` от администратора,
     чип `RV1106`, `Firmware` → образ → `Upgrade`;
   - CLI: `C:\Users\yoy70\SocToolKit\bin\windows\upgrade_tool.exe uf update.img`;
   - скрипт:
     `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\flash_usb.ps1 -Image <update.img> -Force`.
5. Перезагрузить и проверить UART (скорость уточнить: 115200/1500000).

## 4. microSD
1. Записать образ побайтово (Rufus / balenaEtcher / `flash_sd.ps1`).
2. Вставить карту, включить плату.
3. Если грузится SPI NAND, а не SD — переключить порядок загрузки или
   стереть/перепрошить NAND.

## 5. Восстановление
- Плата не грузится: снова Maskrom + `upgrade_tool uf`.
- Сбой NAND: полный образ перезаписывает разделы; при необходимости — erase
  в SocToolKit.
- Сбой SD: перезаписать карту, NAND не трогается.
- До первой прошивки плата была пустой, дамп снять было нельзя.

## 6. Инструменты
- Драйвер, SocToolKit, `upgrade_tool` — уже установлены (см. `04`).
- Запись SD: Rufus/balenaEtcher или `scripts/flash_sd.ps1`.
- UART: PuTTY/Tera Term.
- Runbook по процедуре (Pico Ultra, шаги те же):
  `C:\Users\yoy70\Grom4lte\docs\luckfox-flashing.md`.

## 7. Риски
- Питание при прошивке должно быть стабильным; не отключать USB.
- Чужой образ даёт нерабочую периферию (камера/USB/сеть).
- Для радио нужен USB-host и питание стика AR9271 (Type-C один).
