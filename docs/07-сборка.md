# 07. Сборка образа

## База
SDK: masha **v1.8.0** (`5e7ad171c3`), worktree
`~/rv1106-sdk/bort4g-joy`. Профиль: SPI NAND 256 МБ, CMA 32M,
USB host/HID, eudev, с минимальным набором сервисов.

## Требования
- WSL/Linux, Ubuntu 22.04+; проверено на 26.04.
- Python 3, `rsync`, build-deps SDK.
- Фиксы хоста уже в скриптах:
  `CMAKE_POLICY_VERSION_MINIMUM=3.5`, каталоги e2fsprogs, media samples off.

## Сборка
```bash
export SDK_DIR=$HOME/rv1106-sdk/bort4g-joy

./scripts/prepare.sh          # профиль LCPI_JOY + eudev + DTS host
./scripts/build.sh            # allsave + overlay + repack
./scripts/build.sh --repack-only --skip-prepare   # только образ
```

Результат: `dist/lcpi-joy.img` + `.sha256`.

## Что попадает в образ
- `/opt/pi4joy/pi4joy` (ARMv7, static), `slots.default.json`.
- `/etc/init.d/S95pi4joy`, `/etc/init.d/S41net` (`.251`).
- eudev (`by-path`), sshd, сеть; лишние сервисы удалены.
- Токен и source — `/etc/pi4joy/env` (локальный, не в git).

## Проверка
```bash
./scripts/check.sh            # shell + обязательные документы
./scripts/status.sh           # прогресс/этапы сборки
```
