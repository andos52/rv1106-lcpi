# 04. Сеть и адреса

Подсеть: **192.168.127.0/24**.

| Устройство | IP | Примечание |
|---|---|---|
| НСУ | **192.168.127.250** | nginx :80, WS ingest, API |
| Узел джойстиков | **192.168.127.251** | статический, `S41net` |
| Рабочий ПК | 192.168.127.252 | диагностика |
| Broadcast | 192.168.127.255 | — |

## Порты
- НСУ: `80` (HTTP/WS), локально `8080` (cascade-core).
- pi4joy: `127.0.0.1:8090` (локальный health/slots/state/ws).

## Идентичность
- `PI4JOY_NSU_URL=ws://192.168.127.250`
- `PI4JOY_NSU_SOURCE=pi4joy`
- `PI4JOY_NSU_TOKEN` — `CASCADE_JOYSTICK_INPUT_TOKEN` со станции.
- Слоты: порт USB → слот 1..4, запечены в `slots.default.json`.

Часы НСУ/платы могут быть неверными (RTC/NTP) — это портит `LastSeen` и
логи; для полевых проверок синхронизировать время.
