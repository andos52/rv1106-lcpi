# 07. Сборка радио-образа masha v1.8.0 под LCPI

## 1. Две базы проекта
| База | Путь | Назначение |
|---|---|---|
| `usalko/luxfox` | `~/rv1106-sdk/luxfox` | bring-up образ (уже прошит) |
| masha **v1.8.0** | `~/rv1106-sdk/bort4g-radio` | целевой радио-образ |

`bort4g` HEAD (`grom4-board`) — LTE/WireGuard-ветка, **не используется**.
Копия `~/rv1106-sdk/bort4g-lcpi` — её неудачная сборка, тоже не нужна.

## 2. Worktree v1.8.0
Создан из `~/bort4g`:
```bash
git -C ~/bort4g worktree add ~/rv1106-sdk/bort4g-radio v1.8.0
```
Тег `v1.8.0` = `5e7ad171c3`, содержит `radiod`, `ulama`, `unow`, `vcpd
transport=radiod`, `S39wifi`, `ath9k_htc`/`ath9ku`, AR9271 firmware.

## 3. Подготовка профиля
```bash
SDK_DIR=$HOME/rv1106-sdk/bort4g-radio ./scripts/prepare_radio.sh
# или для джойстиков:
SDK_DIR=$HOME/rv1106-sdk/bort4g-radio ./scripts/prepare_joy.sh
```
`prepare_radio.sh` / `prepare_joy.sh` используют общий
`scripts/lib/common.sh`: создают LCPI-профиль из Pro Max (если его нет),
кладут DTS, ставят CMA 32M, отключают `rkipc`/тесты/вендорный Wi-Fi,
создают каталоги e2fsprogs и отключают media samples.

## 4. Сборка
```bash
# полная сборка joy-образа
./scripts/build_joy.sh

# только перепаковка после правки overlay/env (rootfs уже собран)
./scripts/repack_joy.sh
```
Результат: `dist/lcpi-joy.img` (+ `.sha256`). Радио-сборка:
```bash
cd ~/rv1106-sdk/bort4g-radio
CMAKE_POLICY_VERSION_MINIMUM=3.5 ./build.sh allsave
```
Проверка репозитория без SDK: `./scripts/check.sh`.

### Блокер Buildroot (исправлено 2026-11-15)
Сборка падала на rootfs:
```
make[1]: *** No rule to make target 'luckfox_pico_defconfig'. Stop.
```
Причина: в worktree не было распакованного исходника Buildroot.
Исправление: исходник скопирован из `~/bort4g` (513 МБ, без `output/`),
сборка `allsave` перезапущена. Ждём `output/image/update.img`.

## 5. Особенности хоста
- WSL Ubuntu **26.04** (SDK рекомендует 22.04); базовые проверки проходят.
- Нужны фиксы:
  - `CMAKE_POLICY_VERSION_MINIMUM=3.5` (CMake 4.x);
  - `scripts/fix-e2fs-dirs.sh` (coreutils 9.x, e2fsprogs);
  - отключение `media/samples` (нет RockIVA headers).
- Сборка идёт в Linux-ФС, не в `/mnt/c`.

## 6. Мониторинг
```powershell
.\scripts\build-status.cmd
# или
wsl -d Ubuntu bash /mnt/c/Users/yoy70/RV1106/scripts/status.sh
```
`status.sh` по умолчанию смотрит `~/rv1106-sdk/bort4g-radio`; другой SDK:
`SDK_DIR=... status.sh`.

## 7. После сборки
1. Прошить `update.img` через Maskrom (`08-прошивка.md`).
2. UART: проверить загрузку, NAND, `S39wifi`, `S96radiod`.
3. Определить video-узел камеры и при необходимости поправить
   `/etc/vcpd.conf` (`source=`).
4. Подключить AR9271 через powered hub/OTG, проверить `mon0` ch6.
5. Проверить видео на НСУ и восстановление после reboot.

## 8. Риски
- 128 МБ RAM и CMA 32 МБ: возможен дефицит для MPP/радио.
- Неверный DTS: Ethernet/камера/USB могут не подняться.
- Buildroot v1.8.0 и Ubuntu 26.04: возможны новые несовместимости.
- Радио-часть требует AR9271; MW300UH не поддерживается этим образом.
