# 01. Плата

**LCPI-RV1106 V1.4** (LC Technology) — компактный узел джойстиков.

| Параметр | Значение |
|---|---|
| SoC | Rockchip **RV1106G2**, Cortex-A7 + RISC-V |
| RAM | **128 МБ** DDR (в корпусе) |
| Постоянная память | **256 МБ SPI NAND** (W25N02KV) |
| USB | 1 × Type-C, **host/device; VBUS не выдаёт** |
| Сеть | 100 Мбит Ethernet |
| Карта | microSD |
| GPIO | 2×20 отверстий, официальной pinout нет |
| UART | 3.3 В TTL, **115200**, `root` / `luckfox` |
| Питание | 5 В / 2 А Type-C + питание USB-устройств |

## Роль
Плата работает только как **узел джойстиков**: до 4 USB-пультов → evdev →
pi4joy → Ethernet → НСУ. 

## Ограничения
- Type-C не подаёт 5 В на USB-устройства: нужен **powered hub** или
  разветвитель «данные + питание».
- Одна USB-шина: все пульты через хаб.
- 128 МБ RAM / 256 МБ NAND: минимальный rootfs, без записи данных/логов.
- 2×20 без схемы: UART/GND ищутся прозвонкой.
