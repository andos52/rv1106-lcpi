# 02. Архитектура

```
USB-пульты (до 4, TX12)
   │ HID / evdev
   ▼
udev → /dev/input/by-path/*-event-joystick
   ▼
pi4joy (Go, 32-bit ARM)
   │ 4 слота × 16 RC-каналов, JSON WebSocket
   ▼
Ethernet 192.168.127.251 → НСУ 192.168.127.250:80
   ▼
cascade-core → joystick registry → CONTROL/CRSF
```

## Компоненты
- **udev** — стабильные `by-path` ссылки, слот привязан к USB-порту.
- **pi4joy** — читает evdev, нормализует 16 каналов, ведёт 4 слота,
  отдаёт локальный API (loopback) и исходящий WS на НСУ.
- **slots.default.json** — фиксированный mapping:
  `0:1.3→1`, `0:1.4→2`, `0:1.1→3`, `0:1.2→4`.
- **НСУ** — `remote-pi4joy-<slot>`, sticky-привязка к бортам, UI.

## Потоки
- pi4joy → НСУ: **50 Гц** при изменении, **5 Гц** keepalive в покое;
  16 каналов на слот, только значения RC/control, без потока осей.
- НСУ UI: snapshot ~1 Гц, опрос `rc-status` 1 Гц на привязанный борт.
- Локальный API pi4joy — только петля (по умолчанию `127.0.0.1:8090`).

## Слоты и порядок
- Пульт → USB-порт → слот 1..4; слоты не меняются при hot-plug.
- Карточки в UI идут строго по ID борта: 1 сверху, 4 снизу; активность
  меняет только подсветку.
- API и формат данных: `03-api-contract.md`.
