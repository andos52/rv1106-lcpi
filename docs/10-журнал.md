### Чтение Flash ID / Chip Info
В чистом Maskrom (без загруженного loader) команды не проходят:
```text
RID -> Read flash ID Fail!
RFI -> Read flash Info Fail!
RCI -> Read Chip Info Fail!
PL  -> Reading partition info from device failed!
```
Это ожидаемо: для чтения NAND и таблицы разделов нужен loader
(`DB <loader>` / загрузка из SDK `rkbin`). Повторить после сборки SDK.

### Кабель-разветвитель USB (1×A-папа → 2×A-мама)
- Ветка со значком USB — данные (D+/D-), ветка с молнией — только питание
  (VBUS/GND); это инжектор питания, а не USB-хост.
- Для USB Wi-Fi он сам по себе не подходит: нужен host/OTG-режим Type-C
  платы и powered hub (или OTG-Y с внешним питанием).
- Для прошивки разветвитель не нужен: прямое подключение Type-C к ПК.
