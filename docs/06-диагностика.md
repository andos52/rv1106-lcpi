# 06. Диагностика и нагрузка

## Текущее состояние
- Долгого появления/исчезновения нет; USB-ошибок в текущем `dmesg` нет.
- НСУ: `cascade-core` ~2.4% CPU, RSS ~16.8 МБ, warning/error за час — нет.
- 4 пульта проверялись; сейчас может быть подключено меньше.
- Время НСУ/платы может быть неверным — `LastSeen` в API будет старым.

## Трафик
- 16 RC-каналов на слот, 4 слота, JSON WebSocket.
- Кадр: 330 Б (1 online), 624 Б (3), 771 Б (4).
- До idle-фикса: ~36.5 КБ/с TX при 4 пультах (50 Гц всегда).
- После фикса: ~12.8 КБ/с (джиттер TX12); при стабильных стиках ~4 КБ/с.
- Добавлено квантование ключа 5 мкс: в кадр идут точные значения, но
  суб-5мкс джиттер больше не считается изменением. Ожидается приближение
  к ~4 КБ/с; замер нужно повторить при подключённых пультах (сейчас на
  плате 0 online, одно USB-устройство в STM32 bootloader).
- НСУ UI: snapshot 1 Гц + `rc-status` 1 Гц на борт — мало.

## Замеры
```sh
# на плате
dmesg -w -T | grep -iE 'usb|hid|input|1209|descriptor'
scripts/test-replug.sh 120   # предварительно скопировать на плату
cat /proc/net/dev; sleep 10; cat /proc/net/dev
wget -qO- http://127.0.0.1:8090/healthz
wget -qO- http://127.0.0.1:8090/api/v1/slots

# на НСУ
curl -s http://192.168.127.250/api/v1/joysticks
ps -eo pid,pcpu,pmem,rss,args | grep [c]ascade-core
sudo -n journalctl -u cascade-core -S -1h -p warning --no-pager
date -u
```

## Известные зацепки
- **Часы**: НСУ/плата могут отставать; RTC `1970`. Синхронизировать.
- **Джиттер TX12** не даёт idle-кадру быть байт-в-байт стабильным;
  для минимума — дедзона/квантование или `PI4JOY_NSU_RATE=25`.
- **Перемешивание слотов** было из-за старых sticky-привязок
  (`remote-3→4`, `remote-4→3`); нормализовано в
  `joystick-assignments.json`.
- **Watchdog pi4joy** пока не добавлен: сервис запускается один раз.

## Критерии
| Проверка | Норма |
|---|---|
| Реплаг | ≤1.5 с, без `-32/-110` |
| Idle | ≤4 КБ/с после стабилизации |
| Active | ~30–40 КБ/с на 4 слота |
| CPU НСУ | <5% |
| Слоты | все online, номера не меняются |
| Логи | без warning/error 30 мин |
