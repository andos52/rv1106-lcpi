# 09. План работ

## 1. Этапы
| Этап | Содержание | Критерий |
|---|---|---|
| M0 | Идентификация, Maskrom, инструменты | плата/память подтверждены, прошивка работает |
| M1 | Bring-up образ | прошит; UART/SSH/NAND ещё не подтверждены |
| M2 | Радио-сборка v1.8.0 | `update.img` собран под LCPI |
| M3 | Загрузка и камера | UART, `/dev/video*`, MPP-поток |
| M4 | Радио и НСУ | `mon0` ch6, radiod/ULAMA, видео в UI |
| M5 | Стабильность и серия | reboot-восстановление, конфиг/повторяемость |
| M6 | **Pi4Joy (приоритет)** | 4 джойстика, WS 8090, НСУ видит слоты |
| M7 | Дрон-радио | отложено до готовности Pi4Joy |

## 2. Ближайшие шаги
1. Пропатчить pi4joy под 32-бит evdev (16 байт) и собрать `linux/arm`.
2. Включить USB host/HID и eudev (by-path) в профиле `lcpi_joy`.
3. Собрать joy-образ и проверить `/dev/input`, healthz, слоты в НСУ.
4. Радио-сборку v1.8.0 (`lcpi_radio`) держать отложенной.

## 3. Открытые вопросы
1. USB-host и питание AR9271 на единственном Type-C.
2. Фактический video-узел камеры (`/dev/video0` vs `/dev/video14`).
3. Достаточно ли 128 МБ RAM для MPP + radiod + сервисов.
4. Есть ли у пользователя AR9271 (MW300UH не подходит этому образу).
5. Скорость UART-консоли.

## 4. Решения
- Целевой режим — **радио masha v1.8.0**: AR9271 на борту,
  `radiod`/ULAMA, `vcpd --transport radiod`.
- LTE-модем и WireGuard (`bort4g` HEAD) не используются.
- Приём видео на борт не требуется.
- Прошивка — USB Maskrom (`upgrade_tool`) и microSD.
- Логи — tmpfs + persist в userdata; NAND не изнашиваем.

## 5. Риски
| Риск | Влияние | Смягчение |
|---|---|---|
| Нет Buildroot source в worktree | сборка не идёт | скопировать из `~/bort4g` |
| Ubuntu 26.04 vs 22.04 | сбои сборки | фиксы CMake/e2fs, Docker при необходимости |
| USB-host/питание | стик не работает | powered hub/OTG, проверить `lsusb` |
| 128 МБ RAM | OOM/просадки | CMA 32 МБ, минимум сервисов |
| Неверный DTS | нет камеры/сети | UART-итерации, схема LC Tech |
| Не тот стик | нет радио | AR9271; MW300UH — отдельный драйвер |
