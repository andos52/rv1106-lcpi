# 14. Сеть: известные адреса

Подсеть стенда: **192.168.127.0/24**.

| Устройство | IP | Примечание |
|---|---|---|
| НСУ (станция `msh4`, Pi 5) | **192.168.127.250** | nginx :80 (`/healthz`), cascade-core `127.0.0.1:8080` |
| **Pi4Joy (прежний)** | **192.168.127.251** | источник `pi4joy`, локальный WS `:8090` |
| Pi4Joy (наш RV1106, цель) | **192.168.127.251** | тот же адрес, что у прежнего |
| Бортовые камеры Luckfox | 192.168.127.1 / .2 / .3 | node_id 1..3; **не занимать** |
| Рабочая станция (Ethernet 4) | 192.168.127.252 | текущий ПК |
| Broadcast | 192.168.127.255 | — |

Исторические/другие стенды: `.254` (пульт/node 254), `.252` в старых
MESH-CHECK — для текущего НСУ **не использовать**.

## Адреса сервисов
| Сервис | Адрес |
|---|---|
| NSU ingest джойстиков | `ws://192.168.127.250/api/v1/ws/joystick-input?source=pi4joy` |
| NSU health | `http://192.168.127.250/healthz` |
| NSU API (локально на станции) | `http://127.0.0.1:8080` |
| pi4joy локально | `http://127.0.0.1:8090` (`/healthz`, `/state`, `/ws`) |
| pi4joy → NSU | `PI4JOY_NSU_URL=ws://192.168.127.250` |

## Обязательные совпадения с прежним Pi4Joy
- IP: **192.168.127.251/24** (не `.1` — он занят камерой node 1).
- `PI4JOY_NSU_SOURCE=pi4joy` (не `pi4joy-rv1106`), иначе НСУ увидит
  новые ID `remote-pi4joy-rv1106-*`.
- `PI4JOY_NSU_TOKEN` = `CASCADE_JOYSTICK_INPUT_TOKEN` на НСУ.
- Порт локального WS — `8090`; NSU — `ws://192.168.127.250` (порт 80).

## Как задаётся IP на текущем образе
`S41eth0-static` берёт `node_id` из `/oem/etc/radiod.conf`:
`192.168.127.<node_id>`. Для Pi4Joy нужно **`node_id=251`**
(файл `/oem/etc/radiod.conf`).

## Слоты и порты USB (важно)
pi4joy привязывает слот к USB-порту (`by-path`), а НСУ публикует
`remote-pi4joy-<slot>`. Привязка хранится в
**`/userdata/pi4joy/slots.json`** (правится вручную + restart).

- Прямой порт/хаб-порт 1 (`0:1.3`) → слот 1 → `remote-pi4joy-1`.
- Хаб-порт 2 (`0:1.4`) → слот 2 → `remote-pi4joy-2`.
- Хаб-порт 3 (`0:1.1`) → слот 3 → `remote-pi4joy-3`.
- Хаб-порт 4 (`0:1.2`) → слот 4 → `remote-pi4joy-4`.

Все четыре порта проверены по очереди: НСУ публикует
`remote-pi4joy-N` (drone N) для порта N.

Текущий `slots.json` (записан в `/userdata/pi4joy/slots.json`):
```
0:1.3 -> 1
0:1.4 -> 2
0:1.1 -> 3
0:1.2 -> 4
```
Порты хаба не совпадают с номерами sysfs; привязка — только этим файлом.
